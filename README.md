# MANTIS

Grok-powered autonomous launch hunter for Robinhood Chain.

MANTIS scans new token launches, analyzes on-chain signals, evaluates narrative momentum, and produces AI-assisted trade decisions.

> Status: early development / paper-trading first.

## Planned modules

- Launch detector
- On-chain scanner
- Creator / deployer analysis
- Grok narrative agent
- Risk scoring
- Paper trading engine
- Live terminal dashboard

Roadmap
